# 数据字典（初稿）

核心域：用户与角色、门店、供应商、分类、商品、门店商品最新已知库存、POP 库存快照、库存同步记录、仓库货位、商品货位、导入模板、导入批次、每日销售事实、评分配置、Agent 会话与运行记录。

## 商品公开字段

条形码、供应商、商品名称、规格、单位、分类、所属门店当前售价、状态，以及当前用户所属门店的最新已知库存和最后同步时间。普通用户响应不包含其他门店售价。

## 管理员字段

在公开字段基础上包含各门店当前售价、当前进价、各门店最新已知库存、库存最后同步时间、销售数量、销售金额、成本、利润和毛利率。

## 商品单位

- 商品单位直接保存为自由文本，例如“个”“瓶”“盒”“袋”，不关联单位字典，也不建设独立的单位管理功能。
- 管理员可在商品维护接口和页面修改单位；普通用户只能在商品目录查看。
- 商品资料导入时，已有商品的非空单位覆盖旧值，空单元格按通用非空覆盖规则保留旧值。

## 商品分类

- 商品分类是全系统共享的多级父子层级，不按门店隔离；根分类没有父级且计为第 1 级，最大为第 5 级。
- 商品通过商品资料首次进入本系统时，以表内 POP 商品类别初始化商品分类；普通用户和管理员均可创建父级分类，并调整已有类别的父级归属。
- 商品只能直接关联没有子分类的叶子分类；分类不能同时直接关联商品并拥有子分类。商品资料匹配到已有子分类的 POP 类别时，预检报错并阻断整批提交。
- 商品只保存一个当前有效分类 `categoryId`，不保存最近一次 POP 分类或商品分类来源状态，也不提供恢复 POP 分类能力。
- 已有商品后续无论导入商品资料还是每日销售汇总，都不得修改其 `categoryId`；管理员可以在页面把商品调整至其他启用的叶子分类，普通用户只读，手工调整记录新旧分类并触发商品搜索索引同步。
- 管理员停用分类时不级联修改已关联商品；商品继续保留分类并显示停用状态，商品自身状态不变。停用分类不得用于新的商品创建或手工分类调整；首次进入系统的新商品匹配到停用 POP 分类时的规则待确认。
- 分类调整父级时必须阻止指向自身或后代，避免形成循环；创建或移动后的整个子树不得超过第 5 级，目标父分类不得已有直接关联商品。关联商品的分类不物理删除，通过状态停用。
- 普通用户可创建分类和调整父级，但不能重命名、启用或停用分类；重命名和状态维护仅管理员可执行。
- POP 来源类别保存品类编码，该编码在全系统唯一并作为导入匹配键，不允许通过分类维护页面修改。
- 人工父级分类不保存业务编码，创建时只填写名称，由系统内部 ID 标识并参与父子关系。
- POP 商品资料只有品类编码和品类名称，不能表达父级链路；导入不得根据名称猜测层级。系统中首次出现的 POP 商品类别创建为根分类；已有类别按品类编码匹配，后续导入不得覆盖其名称、状态或父级关系。

## 供应商进价口径

- 商品与供应商为多对多，每个“商品 + 供应商”关系只保存最新进价和进价来源日期，不建设历次进价历史。
- 商品资料中的含税成本价以资料日期、每日销售中的当前机构最后进价以营业日期更新供应商当前进价；只有来源日期不早于现值来源日期时才覆盖，同日以最后成功提交为准。每日销售中的进价还要同时保存为历史销售成本快照。
- 普通用户只能查看供应商名称，不能查看进价；供应商主档、商品供应商关系和报价变化不进入业务审计。

## 售价口径

- 当前售价属于“门店 + 商品”关系，同一条码在不同门店可以不同，不在全局商品主档保存唯一售价。
- 普通用户只读取账号所属门店当前售价；管理员可查看和维护各门店当前售价。
- 管理员修改某一门店售价时，不影响其他门店售价，也不回写历史销售事实。
- 每个门店商品当前售价同时保存售价来源日期，不能只保存金额而丢失覆盖时序依据。
- 商品资料导入前由管理员必选资料日期，代表 POP 导出数据日期；商品资料中的售价仅在资料日期不早于现有售价来源日期时更新所选门店当前售价。
- 每日销售表中的“当前机构”就是目标门店；“当前机构售价”保存为销售快照，并在营业日期不早于现有售价来源日期时覆盖目标门店当前售价。更早的销售导入不回退当前售价，同日以最后成功提交批次为准。
- 管理员手工修改门店售价时不输入日期；系统以 `Asia/Shanghai` 的操作当天作为售价来源日期、以服务器时间记录精确操作时间，来源类型记为手工修改。同日仍以最后一次成功操作为准。

## 库存口径

- POP 是唯一权威库存来源，本系统不使用销量计算库存。
- POP 中商品和库存数据完整，商品资料可导出单门店全部商品并包含零库存、已停用商品；新系统允许分批同步，每批只覆盖出现商品的门店库存。“尚未同步”不表示 POP 缺少该商品或尚未完成实体入库。
- 每日销售汇总只覆盖文件中出现商品的库存；缺失商品保持原值。
- 当前库存必须附带来源批次、来源营业日期和最后同步时间。
- 库存差异仅表示两次 POP 观察值之差，不解释为销售、进货或盘点流水。

## 商品资料合并口径

- 商品资料按条码 upsert；已有条码只用校验通过的非空值覆盖对应字段。
- 商品资料批次保存管理员选择的资料日期；该日期同时作为批次中进价、门店售价和库存的来源日期，不能用上传或提交日期替代。
- 条码是 1 至 64 位数字或英文字母组成的字符串，保留前导零，是可由管理员受控修改的当前业务唯一标识，不作为数据库主键；普通用户不能修改。修改条码时内部商品 ID 及其历史销售、库存和关系数据保持不变；不保存可参与匹配的旧条码别名，导入只匹配当前条码。
- 已有条码的空单元格表示“不更新”，保留系统旧值，不表示清空或写零。
- 新商品缺少必填字段，以及任意非空字段格式错误，均为错误行并阻断整批提交。
- 供应商字段为空时保留现有商品供应商关系，不删除关系。

POP 两类 Excel 的最终表头别名在取得脱敏样表后补充；系统通过可保存的映射模板解耦列顺序和表头差异。

## 销售历史与查询窗口

- 每日销售事实长期保留，首版不自动删除，也不只保存最近一个月。
- 用户选择的主查询区间最多连续 31 个自然日，开始日期和结束日期都计入范围。
- 同比、环比由后端基于主查询区间自动读取等长历史区间，不要求用户另行扩大查询窗口。
- 同比固定使用主查询区间向前推一个自然年的对应日期区间；环比固定使用紧邻主查询区间之前、包含相同自然日数量的连续区间。

## 零销量行

- 每日销售源行的“本期销售数量”等于 0 时整行舍弃，不创建或修正每日销售事实，也不更新供应商当前进价、门店当前售价或最新已知库存。
- 销售收入是否为 0 不改变该规则；过滤在同条码聚合之前执行。
- 负销量不属于零销量行，仍保留为退货事实，但不使用销量加减库存。
- POP 每日销售表中的同期销售收入、同期销售数量和同期销售毛利率全部舍弃，不落库、不参与计算，也不在历史不足时补值。
- 历史不足时比较结果标记为不可用，增长率返回空值，页面显示“暂无可比数据”，不能显示为 0%。
- 31 日限制约束单次交互和分析范围，不是数据生命周期；原始导入文件、审计日志的保留期限另行确认。

## 毛利率口径

- 商品资料中的毛利率舍弃，不进入商品主档、门店商品或商品供应商关系，也不作为商品导入目标字段。
- 每日销售表中的销售毛利率按门店、营业日期、商品保存为销售事实快照，管理员经营分析使用该快照。
- 商品售价或供应商当前进价后续发生变化时，不回写历史销售毛利率；普通用户不能查看销售毛利率。

## 业务审计日志

- 审计日志记录关键业务操作的操作人、发生时间、模块、动作、目标对象、所属门店、执行结果、请求追踪号和必要变更摘要，仅管理员可查询。
- 它不等于销售事实、库存快照或应用运行日志；程序异常和错误堆栈进入应用日志。
- 不保存密码、令牌、会话值、API Key、数据库凭据、完整请求体或完整 Excel 行内容。
- 首版不提供审计记录修改和删除接口；供应商及其报价变化按业务约定不进入审计。审计日志具体保留期限在上线门禁 G5 确认。
