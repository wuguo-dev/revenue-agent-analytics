# 数据字典（初稿）

核心域：用户与角色、门店、供应商、分类、商品、门店商品最新已知库存、POP 库存快照、库存同步记录、仓库货位、商品货位、导入模板、导入批次、每日销售事实、评分配置、Agent 会话与运行记录。

## 商品公开字段

条形码、供应商、商品名称、规格、单位、分类、售价、状态，以及当前用户所属门店的最新已知库存和最后同步时间。

## 管理员字段

在公开字段基础上包含当前进价、门店最新已知库存、库存最后同步时间、销售数量、销售金额、成本、利润和毛利率。

## 库存口径

- POP 是唯一权威库存来源，本系统不使用销量计算库存。
- POP 中商品和库存数据完整，商品资料可导出单门店全部商品并包含零库存、已停用商品；新系统允许分批同步，每批只覆盖出现商品的门店库存。“尚未同步”不表示 POP 缺少该商品或尚未完成实体入库。
- 每日销售汇总只覆盖文件中出现商品的库存；缺失商品保持原值。
- 当前库存必须附带来源批次、来源营业日期和最后同步时间。
- 库存差异仅表示两次 POP 观察值之差，不解释为销售、进货或盘点流水。

## 商品资料合并口径

- 商品资料按条码 upsert；已有条码只用校验通过的非空值覆盖对应字段。
- 条码是 1 至 64 位数字或英文字母组成的字符串，保留前导零，是可由管理员受控修改的当前业务唯一标识，不作为数据库主键；普通用户不能修改。修改条码时内部商品 ID 及其历史销售、库存和关系数据保持不变；不保存可参与匹配的旧条码别名，导入只匹配当前条码。
- 已有条码的空单元格表示“不更新”，保留系统旧值，不表示清空或写零。
- 新商品缺少必填字段，以及任意非空字段格式错误，均为错误行并阻断整批提交。
- 供应商字段为空时保留现有商品供应商关系，不删除关系。

POP 两类 Excel 的最终表头别名在取得脱敏样表后补充；系统通过可保存的映射模板解耦列顺序和表头差异。
