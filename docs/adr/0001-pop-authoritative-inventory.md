# POP 是库存的唯一权威来源

本系统不再根据初始化库存和每日销量推算库存，而是使用 POP 导出的门店商品库存直接覆盖对应的最新已知库存。POP 中的商品和库存数据完整，并可导出包含零库存和已停用商品的单门店完整商品资料；新系统允许将其拆成多份、分批同步。每个商品资料批次和每日销售批次都只覆盖其中出现的条码，未出现商品保持原值。系统保存来源类型、批次、日期、观察时间和同步差异。

## Considered Options

- 初始化库存持续扣减销售：因系统缺少采购、盘点、报损和调拨等全部事件而放弃。
- 同时维护理论库存和 POP 库存：因口径复杂、用户容易混淆而不纳入首版。

## Consequences

- 销售导入和修正不再产生库存加减流水。
- 当前库存仅在文件出现对应条码时被覆盖，缺失商品绝不自动清零。
- 商品资料可拆分成多个批次并重复导入，用于初始化或刷新库存，但不是进货累加。
- 商品资料批次必须由管理员选择资料日期；该日期作为库存来源追溯字段，不参与覆盖优先级判断。最后成功提交的 POP 批次覆盖门店当前库存。
- 商品资料批次按条码 upsert：新条码新增商品主档及门店关系，已有条码更新资料并覆盖该店库存。
- “新增”仅指新增到本系统，不代表商品尚未进入 POP、尚未采购或尚未完成实体入库。
- 每个批次按局部覆盖处理，不执行全量缺失校验；未出现商品不清零、不停用，也不阻断提交。
- 商品页面与库存汇总必须显示最后同步时间；汇总只能称为“最新已知库存”。
